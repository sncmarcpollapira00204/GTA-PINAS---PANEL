Recommended Monthly Migration Order

1. Restore your latest JSON backup. 2. Import Open Tickets from Discord. 3. Import Closed Transcripts from Discord. Every operation is merge-safe, so running it again will update records instead of creating duplicates.

1. Restore JSON Backup

Fastest and most complete restore. It preserves ticket IDs, messages, staff records, logs, and saved HTML transcripts.

2. Import Open Tickets

Scans private ticket channels, including tickets moved into staff categories. Restores owners, handlers, messages, embeds, replies, and attachments.

3. Import Closed Transcripts

Scans current and legacy transcript log channels, downloads each HTML file, and restores closed-ticket metadata and transcript viewing.

Discord-Only Full Recovery

Use this when no JSON backup is available. It runs Open Ticket recovery first, followed by Closed Transcript recovery.
